# 第七章「俺が決める」
# ============================================================
@label ch7_start
@bg ward_room
@chapter 第七章|俺が決める
@chara clear
@glitch 0
@flag shouki = 100

こめかみが、ずきずきする。
指で触れると、ガーゼの感触があった。
窓の外は明るい。カーテンが半分だけ開いている。

@chara nurse right
看護師：あ、起きた。おはよう。
看護師：夜中に転んで、頭を打ったのよ。覚えてる？
ぼく：……はい。椅子に、つまずいて。
看護師：縫うほどじゃなかったから、大丈夫。よく寝てたよ、二日も。
ぼく：……二日。

@clear
夢を見ていた。長い夢だった。
勇者の夢。村の夢。井戸のそばで水を汲む、地味な女の子の夢。
細かいところは、もう溶けはじめている。
それでも、最後に言われた言葉だけが、そのまま残っていた。

@caption 「たとえ作られた世界だとしても、私が好きな人は私が決めます」

@clear
ぼく：（……あれ、俺が書いたんだよな）
ぼく：（俺の中に、あれを言えるやつがいたってことだ）
ぼくは、ベッドの上で少しだけ笑った。
笑ったのは、たぶん、何か月ぶりかだった。

# ------------------------------------------------------------
# 退院まで
# ------------------------------------------------------------
@clear
@chara clear
@bg counsel
@chara doctor right
その日の面談で、ぼくは自分から座った。
医師：顔つきが変わりましたね。
ぼく：……そうですか。
医師：薬は続けます。すぐに全部よくなるわけじゃない。それは、わかってほしい。
ぼく：はい。

@choice
- 「作っていたものを、続けたいです」 -> c7_ask
- 黙って頷く -> c7_nod

@label c7_ask
ぼく：ひとつ、お願いがあります。
ぼく：入院中に作っていたものを、続けたいです。パソコンを、少しでいいので。
医師：……時間を決めて、日中だけなら。
医師：その代わり、寝る時間は削らないこと。それが条件です。
ぼく：わかりました。
@jump c7_days

@label c7_nod
ぼくは黙って頷いた。
それでも、面談のあとに看護師を呼び止めて、同じことを頼んだ。
返事は、時間を決めるならという条件つきの「いいですよ」だった。
@jump c7_days

@label c7_days
@clear
@chara clear
@caption それからの一か月は、おそろしく事務的に過ぎた。
朝、決まった時間に起きる。薬を飲む。食事を残さない。
面談で、聞かれたことに丁寧に答える。答えられないことは、答えられないと言う。
夜は消灯までに寝る。抵抗しない。廊下を走らない。
ぼく：（従順にしてるだけだ、と最初は思っていた）
ぼく：（でも、体が整うと、頭の中の水は、たしかに引いていった）

@clear
髪を切ってもらった。爪を切った。パジャマではなく、服を着た。
鏡の中の自分は、相変わらず手足が短くて、顔も平凡だった。
ぼく：（……でも、こいつだ）
ぼく：（俺が動かせるのは、こいつだけだ）

# ------------------------------------------------------------
# 退院の日
# ------------------------------------------------------------
@clear
@bg hospital_out
@chara clear
@chara father right
@chara mother left
退院の日、両親が迎えに来た。
父さんは、苦虫を噛みつぶしたような顔をしていた。
母さんは、ぼくと目を合わせないようにしながら、荷物を持とうとした。
ぼく：自分で持てる。
父さん：…………。
沈黙が、駐車場まで続いた。

@clear
ぼく：あのさ。
父さん：……なんだ。
ぼく：俺、働くよ。
@wait 0.4
ぼくは、ポケットから折りたたんだ紙を出した。
病院の掲示板の隅にあった、泊まり込みの求人のチラシ。
「未経験可・住み込み可／簡単なプログラム作成の補助」

@clear
@chara clear
父さんが、それを受け取って、二度読んだ。
母さんが、横から覗き込んだ。
ふたりとも、目を丸くしていた。
父さん：……お前、これ。
ぼく：面接、来週。自分で電話した。
誰も、しばらく何も言わなかった。
父さん：……そうか。
それだけだった。でも、帰りの車の中で、父さんは一度も舌打ちをしなかった。
