0このマニュアルについて

イズミヤ夜営業を、自分が一人で滞りなく回すための手順書。試験営業のあいだに実測値を書き足しながら育てる前提でつくってある。

使い方の3原則

  • 【　】は未確定。試験営業のなかで実測して埋める
  • ▲ 印は「決めないと運用が止まる論点」。優先して潰す
  • 手順を変えたら、その日のうちに書き込む

このマニュアルが本当に守りたいもの

  1. 間借りである以上「返す状態」が最重要。第7章の撤収基準だけは、疲れていても絶対に飛ばさない。
  2. 試験営業の目的は売上ではなくデータ。第8章の日次記録を書かなかった日は、その営業がなかったのと同じ。

5メニュー別 手順書（フード）

各メニューは「材料の場所 → 手順 → 注意」の順。場所の呼び名は第2章に準拠。

5-1. ニューヨークチーズケーキ

材料の場所

  • ケーキ … 南東下の冷蔵庫
  • ベリー … 南西下の冷蔵庫（青フタの容器）
  • ホイップ … 【　　　】
  • 粉砂糖 … 西上の棚
  • 皿 … 西下（灰青の丸皿）

手順

  1. 西下から灰青の丸皿を出す
  2. 南東下の冷蔵庫からケーキを1切れ取り、紙をはがして皿の中央やや左に置く
  3. 茶こしで粉砂糖をケーキの上に振る
  4. 皿の右にホイップを1つ絞る
  5. ホイップの手前にベリーを載せて完成
注意
  • 粉砂糖が皿の縁につくと汚く見える。ケーキの真上だけに落とす
  • ベリーは汁が広がるのでホイップに寄せて置く

▲ホイップの入手元（缶／自分で立てる／どの冷蔵庫）を確定する

▲カットは仕込みで全カットか、注文ごとか。1本を何等分にするか

5-2. 抹茶チーズケーキ

材料の場所

  • ケーキ … 南東下の冷蔵庫（冷凍品・6個入／京都宇治抹茶チーズケーキ）
  • ホイップ … 南西下の冷蔵庫
  • 粉砂糖 … 西上の棚
  • 皿 … 西下（灰青の丸皿）

手順

  1. 西下から灰青の丸皿を出す
  2. ケーキを1切れ取り、フィルムをはがして皿の中央に置く（三角の頂点を奥に）
  3. 皿の右にホイップを1つ絞る
  4. 茶こしで粉砂糖をケーキの上と皿の余白に振って完成
注意
  • NYと違い、ベリーは載せない
  • 粉砂糖は皿にも散らす方が写真映えする
  • 冷凍品。解凍時間を見込まずに出そうとしない

▲解凍の手順を確定する（前日から冷蔵／何時間前に出す）

6メニュー別 手順書（ドリンク）

計量はすべて ml。メジャーカップを使う。

6-1. アイス抹茶ラテ

道具・材料

  • 厚手のゾンビグラス
  • 抹茶碗（黒）・茶筅・茶こし … バーカウンターのバット上
  • 抹茶・スプーン … バーカウンター
  • お湯 … ポット（EVEREST）／ショットグラス1杯分
  • 牛乳 … 信州高原牛乳
  • ガムシロップ … ポンプボトル

手順

  1. ゾンビグラスに氷を詰めて冷やす。溶けた水は捨てる
  2. 抹茶碗に抹茶をすりきり2杯入れる
  3. ポットのお湯をショットグラス1杯注ぎ、茶筅を縦に動かして混ぜる
  4. グラスに牛乳を注ぐ。氷1個分の高さを残す
  5. ガムシロップを2.5プッシュ入れ、ここで混ぜる
  6. 茶こしでこしながら抹茶を静かに注ぐ。注いだ後は混ぜない
注意
  • ⑤で混ぜる／⑥では混ぜない。順序を逆にすると層が消える
  • 緑と白の2層が完成形
  • 茶こしを通さないとダマが浮いて濁る
  • 牛乳を入れすぎると抹茶が乗りきらない

▲氷は冷やした後そのまま使うか、入れ直すか

▲ストロー／マドラーを添えるか。層のまま出すなら「混ぜてから飲んでください」の案内が要る

6-2. ジントニック

道具・材料

  • クープグラス（脚つき）
  • ジン（BOMBAY SAPPHIRE・青ボトル） … 中央
  • トニックウォーター（缶） … 南東下の冷蔵庫
  • 冷凍レモン … 南西下の冷蔵庫
  • ミント … 南東下の冷蔵庫
  • メジャーカップ … 中央

手順

  1. クープグラスに氷を満載して冷やす。溶けた水は捨てる
  2. ジンを 30ml 注ぐ
  3. トニックウォーターを満タンになるまで注ぐ
  4. 冷凍レモンをのせる
  5. ミントを手のひらで1回叩いて香りを立たせ、のせる
注意
  • ミントは叩かないとただの飾りになる。必ず1回叩く
  • トニックは泡が上がるので、縁ぎりぎりで止める
6-3. レモンサワー

道具・材料

  • 厚手のゾンビグラス
  • こだわり酒場のレモンサワーの素（1.8L・25度） … 中央
  • 焼酎 … 北の棚
  • 炭酸水（ペットボトル） … 東下の冷蔵庫

手順

  1. ゾンビグラスに氷を満たす
  2. レモンサワーの素を 45ml
  3. 焼酎を 10ml
  4. 炭酸水を注いで完成
注意
  • 素は25度の濃縮タイプ。原液のまま出さない
  • 炭酸水は氷に当てず、グラスの内壁を伝わせて注ぐと炭酸が抜けにくい
6-4. ビン飲料（ビール・ジンジャーエール等）＝セルフサービス

提供方法

  • 客が冷蔵庫から自分で取る
  • 栓抜きは 【　　　】 に常設

対応

  • 希望があれば薄手グラスを出す
  • 何も言われなければビンのまま提供
注意
  • セルフである以上、注文漏れ＝売上漏れ。「取る前にQRで注文」の導線を必ず案内する
  • 冷蔵庫のドアに英語の掲示を貼る
  • 冷えるまで最低2時間。開店2時間前の補充を厳守

▲栓抜きの定位置を決めて記入する

▲冷蔵庫ドア用の英語掲示（Order on the QR before taking a bottle）をつくる

10法務・遵守メモ

  • 酒類提供と飲食営業の許可がどの建て付けで成立しているかを、書面で確認しておく（イズミヤの許可の範囲内か、別途届出が要るか）
  • 20歳未満に酒類を提供しない。見た目で迷ったら必ず年齢確認する
  • 車で来た客に酒類を提供しない。南木曽は車移動が前提の客が一定数いる
  • 提供したメニューの原材料表示を保管しておく（アレルギー申告への備え）

▲許可の建て付けを確認し、根拠を書き込む。ここが未確認のまま営業を重ねない
