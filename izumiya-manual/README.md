# イズミヤ 夜営業 運営マニュアル

イズミヤ（南木曽駅前）水曜・木曜夜の間借り営業の運営手順書。
**`index.html` 1枚＋ `images/` フォルダで完結**。ビルド不要、フレームワーク不使用。
ファイルをブラウザで開くだけで表示できます（ダブルクリックでOK）。

## 新メニューの追加手順

1. `index.html` を開き、`メニューカード：新メニューは下のブロックを丸ごとコピー` のコメントを探す（第5章冒頭。テンプレは第5-3章の下のコメント内にもある）
2. `<details class="recipe" ...>` 〜 `</details>` を丸ごとコピーして、追加したい位置に貼る
3. `id="recipe-〇〇"` を新しい名前に変え、メニュー名・材料の場所・手順・注意を書き換える
4. 写真は `images/` に入れて `<img src="images/ファイル名.jpg">` を差し替える（完成形1枚＋つまずきやすい工程）
5. ページ上部の目次 `<nav>` に `<a class="toc-sub" href="#recipe-〇〇">…</a>` を1行足す

既存部分には触らなくてよい。保存してブラウザを再読み込みすれば反映されます。

## 空欄・未決事項の埋め方

- 空欄は `<mark class="blank">【　】</mark>` で黄色く表示される。確定したらマークごと普通のテキストに置き換える
- 未決事項は `<p class="pending">▲ …</p>`。解決したらその行を削除し、第11章の一覧からも消す
- **厨房の平面図**：手書き図を撮影して `images/kitchen-floorplan.jpg` という名前で保存するだけで、第2章の枠に自動表示される

## 印刷

ブラウザの印刷（A4縦）でそのまま紙に出せます。折りたたまれたメニューカードも印刷時は自動で全展開されます。

## 公開（Vercel）について

**原価・仕入れ先・売価を今後書き込むため、パスワード保護なしで公開しないこと。**
Vercel に載せる場合は、プロジェクト設定の Deployment Protection（Password Protection 等）を有効にしてから公開する。当面はローカル閲覧のみでも運用可。
