## 木曽路ダウンヒル — Kiso Valley E-bike Downhill

薮原宿から三留野宿まで、木曽川ぞい 50 km を e-bike で下るミニゲーム。
岩・丸太・猿をよけながら、五平餅を拾ってスコアを稼ぎ、♨ でハートを回復して完走を目指す。

- **遊び方**: `index.html` をブラウザで開くだけ(ビルド不要・依存なし)
- **操作**: ← → キー(または A / D)、スマホは画面タッチ。P で一時停止
- **チェックポイント**: 薮原宿 → 木曽福島 → 上松宿 → 須原宿 → 野尻宿 → 三留野宿(実在の中山道ルート)
- ベストスコアはブラウザの localStorage に保存

素の HTML + Canvas の1ファイル構成。
